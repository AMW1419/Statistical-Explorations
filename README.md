# Statistical-Explorations
A collection of Jupyter notebooks for exploring statistical concepts, descriptive statistics and Python calculations.

## Overview
This repository contains Jupyter notebooks for exploring statistical concepts and performing statistical calculations using Python. These notebooks serve as a reference for practicing data analysis, understanding descriptive statistics and learning how to interpret statistical results.

## Contents
- `descriptive_stats(2).ipynb`: An exploration of descriptive statistics using Python, including calculations and visualizations.

## Tools
- Python
- Jupyter Notebook
- Google Colab

## Purpose
The purpose of this repository is to organize statistical explorations and code examples for future reference and continued learning in data science.
